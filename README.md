# 网页抓取工具

基于 Electron 的桌面抓包 / 爬虫工具：内嵌真实浏览器加载并登录目标站点，抓取**全部请求与响应体、Cookie、Storage、页面 HTML**，并提供数据提取、自动翻页、反爬伪装与多种导出格式。

专为 **Windows 7 SP1 32 位** 老机器适配（Electron 22.3.27 / Chromium 108 / ia32），同时可在 Windows 10/11 直接运行，绿色免安装。

---

## 功能

| 分类 | 能做什么 |
|---|---|
| 抓取 | 全部请求的方法 / URL / 类型 / 状态 / 耗时 / 大小 / 远端 IP；请求头与请求体；响应头与响应体（含二进制 base64）；原始头（含 `Set-Cookie`）；重定向链；失败原因；WebSocket 收发帧 |
| 多标签 | 每个标签独立抓取互不串数据；后台标签继续跑自动化与抓包；关掉最后一个标签自动新建 |
| 页面数据 | 页面 HTML、`document.cookie`、`localStorage`、`sessionStorage`、Cookie 存储（含 httpOnly）、标题 |
| 会话数据管理 | Cookie 增删改 / 批量导入（`a=1; b=2` 或 JSON）/ 导出 JSON 或 Netscape；localStorage 与 sessionStorage 逐项编辑、新增、删除 |
| 检索与列表 | 过滤语法 `method:post status:4xx mime:json domain:x size:>100k time:>500`（前缀 `!` 取反，多条件 AND）；列预设（耗时 / 类型·大小 / 时间戳）；↑↓ 键在列表内移动 |
| 拦截与过滤 | 屏蔽图片/媒体/字体；关键字屏蔽；仅记录 XHR/Fetch；CDP 网络限速（3G / 慢速） |
| 反爬伪装 | UA 预设与自定义、自定义请求头注入、HTTP/SOCKS 代理、请求最小间隔（礼貌抓取，0–10000ms） |
| 兼容性 | 忽略证书错误（内网自签名站点）、Basic 认证用户名/密码自动应答 |
| 数据提取 | CSS 选择器批量提取（`标题=.t` / `链接=a@href` / `正文=@html`）导出 CSV/JSON；页面清单（链接/图片/表单/表格）；表格转 CSV |
| 自动化 | 自动滚动到底（无限加载页面）；自动翻页 N 页（自动识别「下一页」，可随时停止） |
| 页面工具 | 可见区域截图 / 整页截图 / 按 CSS 选择器截图、打印为 PDF、页面内查找（含匹配计数） |
| 结果处理 | 导出全部 JSON、**导出筛选结果**、单条导出、HAR（可直接拖进 Chrome DevTools）、当前页 HTML、Cookie JSON；响应体/请求体单条另存；响应体批量落盘；复制 cURL；请求重放（可改写方法/URL/请求头/请求体） |
| 会话持久化 | 定时与退出时保存最近抓包，重启后横幅一键恢复（或忽略并删除）；超过 7 天视为过期 |
| 诊断 | 未捕获异常兜底（不退出进程）+ `<userData>/logs/app.log` 诊断日志（2MB 滚动，设置里有查看入口） |
| 面板体验 | 面板宽度可拖拽（持久化）、键盘快捷键（Ctrl+L 地址栏 / Ctrl+F 过滤框 / Ctrl+P 暂停 / Esc 关模态或查找 / ↑↓ 选行）、响应体超 200KB 默认截断可展开 |

抓取走 Chrome DevTools Protocol（挂在视图的调试器上），不受页面 CSP 限制，也不需要往页面里注入脚本。

## 环境要求

- 开发：Node.js 与 npm（本项目在 Node 24 + npm 12 下开发）
- 运行（打包版）：Windows 7 SP1 32/64 位 或 Windows 10/11，无需安装 Node

> **Windows 7 注意**：必须已安装 **SP1** 与 SHA-2 代码签名补丁（KB4474419，配套服务栈 KB4490628），否则 Electron 22 无法启动。这是 Chromium 的硬性要求，没有替代方案。

## 快速开始

```bash
npm install
npm_config_arch=ia32 node node_modules/electron/install.js   # 拉取 32 位运行时（npm 会拦 postinstall）
```

### 界面说明

窗口上半部分是**真实浏览器视图**（可直接输入网址、登录、操作页面），右侧面板是抓包列表与详情，顶部四行工具栏：

1. **地址与总控**：前进/后退/刷新、网址输入、打开、暂停抓取、清空、会话数据、导出全部/HTML/Cookie、请求计数与状态
2. **拦截与伪装**：资源拦截模式、关键字、仅记 XHR/Fetch、限速、UA、请求头、代理、请求最小间隔
3. **自动化与提取**：自动滚动、自动翻页、停止、CSS 提取、页面清单、页面查找、截图/PDF、响应体存盘、导出 HAR、导出筛选结果、设置
4. **标签栏**：新增标签、切换、关闭（每个标签独立抓包）

标签栏下方是面板本体：过滤框 + 类型过滤 + 列预设，请求列表 / WebSocket 两个视图，选中行后展开详情。
面板左边缘可拖动调整宽度（重启后保留）；鼠标放在面板左边缘的 6px 区域内会出现拖动条。

点击请求列表任一行展开详情（概要 / 失败 / 重定向链 / 请求头 / 请求体 / 响应头 / 响应体），详情顶部可**复制 cURL**、**重放请求**（可改写方法/URL/请求头/请求体）、**导出此条**、**请求体另存**；响应体区可**另存为文件**，超过 200KB 默认只显示前 200KB，可点「查看全文」展开。

常用快捷键：`Ctrl+L` 聚焦网址栏、`Ctrl+F` 聚焦过滤框、`Ctrl+P` 暂停/继续抓取、`Esc` 关闭模态框或页面查找、`↑`/`↓` 在列表内移动选中行。

## 抓取与导出

- **登录**：直接在视图里登录即可；Cookie 与 localStorage 保存在持久分区，重启后仍保持登录态。
- **导出全部**：页面数据 + Cookie + 全部请求记录（含响应体）+ WebSocket 帧，输出为单个 JSON；点「导出筛选结果」只导出当前列表里筛出来的那些记录，详情里点「导出此条」只导出单条。
- **HAR**：标准 1.2 格式，可用 Chrome DevTools 的 Network 面板直接导入查看。
- **响应体存盘**：选择目录后按 `序号_方法_主机路径.扩展名` 写入文件，重名自动追加 `-1`、`-2`，二进制响应体按原始字节写出；单条响应用详情里的「另存为文件」/「请求体另存」。
- **重放**：在弹窗里可改写方法、URL、请求头（每行 `名称: 值`，大小写不敏感覆盖）与请求体，默认预填抓到的原始内容；结果就地展示（响应体截断到 1MB）并追加到详情面板，不会混入抓包列表。

设置项（拦截/限速/UA/请求头/代理/间隔/证书/认证）中，**拦截、UA、请求头、代理、证书、认证**刷新页面后生效；**限速、仅记 XHR/Fetch、请求间隔**立即生效。所有设置重启后保留。

### 检索语法

过滤框支持字段语法，多个条件用空格分隔且必须同时满足（AND），单个条件前加 `!` 取反：

| 写法 | 含义 |
|---|---|
| `api/data` | URL 子串 |
| `method:post` | 方法完全匹配 |
| `status:4xx` / `status:>=400` / `status:<500` / `status:204` | 状态码：`Nxx` 归类、比较符、精确值 |
| `type:xhr` | 资源类型完全匹配（XHR / Fetch / Script / …） |
| `mime:json` | MIME 子串 |
| `domain:example.com` | 主机名等于或为其子域 |
| `size:>100k` / `size:<1m` | 编码后大小，支持 `k`/`m` 后缀（1024 进制） |
| `time:>500` | 耗时（毫秒） |

例：`type:xhr status:4xx !mime:json` = XHR 里 4xx 且响应不是 JSON 的请求。
列表右上角的列预设可切换第二列显示：耗时 / 追加类型·大小 / 时间戳（选择会随设置持久化）。

### 会话数据

工具栏「会话数据」打开管理面板：

- **Cookie**：逐条改值（`change` 即写回，失败会回滚并提示）、删除、新增（挂到当前页 origin）、导入（粘贴 `a=1; b=2` 或 JSON 数组）、导出 JSON / Netscape（`cookies.txt`，可直接给 `curl -c/-b`、wget 用）。
- **localStorage / sessionStorage**：逐项改值、删除、新增（写操作后界面重新拉取，与浏览器内实际值保持一致）。
- **页面信息**：标题、URL、HTML 长度、`document.cookie`。

## 数据提取与自动化

**CSS 提取**：填入行选择器（如 `.item`）与字段（每行 `名称=选择器[@属性]`），提取结果可预览前 20 行并导出 CSV/JSON。选择器为 `:self` 时取行元素本身；`@href` / `@src` 会自动解析成绝对地址。

**页面清单**：一次性取出页面上的链接、图片、表单、表格，导出 JSON 或把表格合并导出为 CSV。

**自动滚动**：反复滚动到底并等待内容加载，连续两轮高度不再增长即停止（默认 5 轮，最大 50 轮）。

**自动翻页**：自动识别「下一页」（优先 `a[rel=next]`，其次按文案匹配），按设定的间隔翻页，最多 100 页，可随时点「停止」。

## 页面工具

- **页面查找**：工具栏「页面查找」在面板里开一条查找栏，输入即查（CDP 走 `findInPage`），显示 `当前/总数`，↑/↓ 切换上一个/下一个，`Esc` 或 ✕ 结束查找。
- **截图**：可见区域截图、整页截图（自动按内容高度扩展，不需手动滚动）、按 CSS 选择器截图（元素不存在会明确报「未找到匹配元素」）。
- **PDF**：`printToBackground` + A4 打印当前页为 PDF。
- 三者都在「截图/PDF」弹窗里操作，完成后 toast 出落盘路径。

## 会话恢复与日志

**会话恢复**：抓包过程中每 30 秒（记录有变化时）与退出时把最近 2000 条记录（含响应体，总量上限 64MB，超出部分省略响应体并标注原因）与 WebSocket 帧写入 `<userData>/sessions/last.json`。下次启动若文件在 7 天内，面板顶部横幅提示「发现上次会话」：点「恢复」把记录灌回列表（编号续接，新的抓包不会与旧记录冲突），点「忽略」直接删除该文件。

**诊断日志**：`<userData>/logs/app.log`，超过 2MB 滚动为 `app.log.1`（只保留一代）。记录启动失败、渲染进程退出、证书错误、认证请求、IPC 异常与未捕获异常/未处理 rejection；未捕获异常只记日志并在状态栏提示，**不会退出进程**。工具栏「设置」里可直接查看最近 200 行并打开日志所在文件夹。

## 无显卡 / 老旧机器

工具会读取 Chromium 上报的 GPU 状态：若没有可用的硬件加速（驱动缺失、显卡过老、虚拟机、远程桌面），会自动开启软件渲染并在面板顶部给出提示条，点「立即重启」即可生效。GPU 进程反复异常退出时同样会触发。

- **核显照常走硬件加速**（Intel HD/UHD、AMD APU 等），不会被判定为「无显卡」。判定依据是 Chromium 实际上报的合成状态，与是否独显无关。
- 判定采用**双次采样**：启动瞬间的状态可能是瞬时的，两次采样都判定为软件渲染才会写入配置，避免误改。
- 也可手动控制：工具栏「设置」里勾选「强制软件渲染」，或在命令行加 `--software-rendering`。

「设置」对话框中还会显示当前 `gpu_compositing` 原始值、判定结论与 GPU 进程异常次数，便于排查。

## 配置文件

设置保存在 Electron 的 `userData` 目录下：

- 打包版：`%APPDATA%\web-capture-tool\settings.json`
- 开发态：`%APPDATA%\Electron\settings.json`

内容包括抓取设置（拦截/限速/UA/请求头/代理/列预设/请求间隔/证书/认证）、软件渲染开关、面板宽度与窗口位置尺寸。写入采用 300ms 防抖 + 临时文件原子替换；文件损坏时会改名保留为 `settings.bad-<时间戳>.json` 并回退默认值，不会静默丢弃。

同目录下还有两个由工具自己维护的文件：

- `logs/app.log`（+ `app.log.1`）：诊断日志，2MB 滚动。
- `sessions/last.json`：上次会话记录，可一键恢复。

> **Basic 认证密码是明文保存在 `settings.json` 里的**（刻意取舍：工具只在本机使用，且不引入额外加密依赖）。勾选「忽略证书错误」同样会降低连接安全性，请只在确认目标站点的场合开启。

## 自检与打包

```bash
npm run selftest        # 97 项断言：抓取 / 提取 / 自动化 / 存盘 / 持久化 / 图标 / UI / 新功能
npm run selftest:sw     # 同一套断言在软件渲染下再跑一遍（等价于无显卡机器）
npm run icon            # 重新生成 build/icon.ico 与 build/icon-128.ico
npm run pack            # 打包 → dist/web-capture-tool-win32-ia32/ 与同名 .zip
```

自检会在本地起一个测试服务器并驱动真实窗口完成全链路验证；运行期间配置、日志与会话文件都会改道到系统临时目录（`wct-selftest-*`），不影响你的真实配置。脚本弹出的系统保存/目录对话框无法自动化，对应功能通过传入路径参数绕过验证。

打包产出的 exe 内嵌自绘图标（`build/icon.ico`，7 个尺寸）；若某些环境对 256 尺寸解析异常，可把 `pack:dir` 的 `--icon` 换成 `build/icon-128.ico`。

## 目录结构

```
main.js         主进程装配：窗口 / 多标签视图 / IPC / 启动
state.js        共享状态与常量；多标签的「活动标签镜像」与 syncActive()
capture.js      CDP 抓取：Network.* 事件 → 标签内记录，请求重放
settings.js     抓取设置唯一写入口（applySetting）+ 拦截器与请求间隔节流
automation.js   自动滚动 / 自动翻页
extract.js      页面侧采集：HTML/Storage/CSS 提取/页面清单
format.js       纯函数：请求头合并与解析 / cURL / CSV / HAR
files.js        落盘：保存对话框、文本与二进制写入、响应体批量导出
store.js        设置持久化（userData/settings.json）
session.js      会话持久化（userData/sessions/last.json）
logger.js       诊断日志（userData/logs/app.log）
gpu.js          GPU 状态判定
make-icon.js    图标生成器（零依赖，代码绘制）
index.html      面板界面与样式（深色 token 化）
renderer.js     面板逻辑（标签栏/列表/详情/模态框/快捷键/轻提示）
selftest.js     --selftest 全链路自检
```

模块依赖单向：所有模块只 `require('./state')`，禁止反向依赖 `main.js`。

## 已知限制

- 启动开发态与打包态的 `userData` 目录名不同（`Electron` vs `web-capture-tool`），配置不互通。
- Cookie、localStorage 等站点数据位于 `userData` 的持久分区内，清理该分区会同时清掉登录态。
- 抓取记录上限 5000 条/标签、单条响应体 32MB、响应体总量 256MB、WebSocket 帧 2000 条，超出后按策略截断或丢弃并给出提示。
- 多标签只在本次运行内有效：重启后回到单标签（会话恢复只恢复记录，不恢复标签布局）。
- UA / 请求头 / 限速这三项设置作用于**当前活动标签**的视图；新建标签会沿用设置，但已存在的后台标签不会跟着改。
- 后台标签关闭了 `backgroundThrottling` 以便继续抓包与自动翻页，代价是标签越多 CPU 占用越高。
- 页面内查找的匹配计数始终准确；高亮是否可见取决于页面视图当前是否拿到焦点（被遮挡时可能看不到高亮，这是 Chromium 的渲染策略）。
- 「忽略证书错误」只影响本次运行内的连接判定，不改动系统证书库。
- 站点要求 Basic 认证且设置里未填用户名时，会取消请求并在状态栏提示（不弹系统输入框）。
- 代理仅验证配置已生效（`resolveProxy`），真实链路可用性取决于代理服务本身。
- 系统保存/目录对话框需要人工点选，无法纳入自动化测试。
