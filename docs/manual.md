## 1. 安装与启动

**运行要求**：Windows 7 SP1 32 位及以上（打包产物是 ia32，Win10/11 同样可直接跑）；不需要装 Node / 浏览器，Electron 运行时已内置。

| 场景 | 命令 / 操作 |
|---|---|
| 开发态运行 | 先 `npm install`，再 `npm start` |
| 打包绿色版 | `npm run pack` → 产物在 `dist/web-capture-tool-win32-ia32/`，双击 `web-capture-tool.exe`；`npm run pack:zip` 另出一个 zip |
| 不开窗口直接自检 | `web-capture-tool.exe --selftest`（见 [第 17 节](#17-命令行与自检)） |

**配置与数据目录**：所有配置、Cookie、登录态、录制产物都放在 `%APPDATA%\web-capture-tool`，开发态和打包版**共用同一份**（换版本不丢登录态）。目录结构见 [第 21 节](#21-文件目录与命名规则)。

**首次启动会看到什么**：右侧面板 + 左侧空白页区域；状态栏显示「抓取中」即表示 CDP 已挂上，可以开始在地址栏输入网址。

## 3. 五分钟上手

1. 在地址栏输入网址（可省略 `http://`），回车或点「打开」。
2. 页面加载时，右侧列表开始出现请求；**行在底部时自动跟随**，不在底部时会浮出「↓ N 条新记录」按钮。
3. 点任意一行 → 详情面板展开：概要 / 发起者 / 耗时分解 / 失败 / 重定向链 / 请求头 / 请求体 / 响应头 / 响应体。
4. 详情顶部一排按钮：`★ 标记`、备注框、`复制 cURL`、`重放请求`、`导出此条`、`请求体另存`、`复制 URL`、`复制响应头`、`复制响应体`、`复制代码…`、`设为 mock`。
5. 需要留下证据时用第 1 行的 `导出全部`（JSON）或 `导出 HTML`；需要给别人复现时用第 3 行的 `离线包`。

## 4. 请求列表与详情

### 4.1 过滤框（支持一整套语法）

在面板顶部过滤框里输入，语法可混用（空格分隔，多个条件为 AND；前缀 `!` 取反）：

| 写法 | 含义 | 例 |
|---|---|---|
| 裸文本 | URL 子串（不区分大小写） | `api/login` |
| `method:` | 方法 | `method:post` |
| `status:` | 状态码 / 状态段 | `status:4xx`、`status:200`、`status:>=400` |
| `type:` | CDP 资源类型 | `type:xhr`、`type:document` |
| `mime:` | MIME 关键字 | `mime:json` |
| `domain:` | 主机名关键字 | `domain:example.com` |
| `size:` | 响应大小 | `size:>100k`、`size:<2m` |
| `time:` | 耗时（ms） | `time:>500` |
| `star:1` | 只看已 ★ 标记 | `star:1` |
| `body:"文本"` | **响应体全文搜索**（只搜已保存的文本响应体） | `body:"token"` |

- 命中数显示在列表上方（`响应体命中 N 条`），改条件后约 300ms 重算一次。
- 类型下拉与列预设可叠加过滤；列预设：`方法·状态·URL·耗时` / `附加类型·大小` / `时间戳`。
- 排序下拉：时间 / 域名分组 / 大小↓ / 耗时↓ / 状态；选择随设置持久化。

### 4.2 列表操作

| 操作 | 怎样做 | 结果 |
|---|---|---|
| 选中并看详情 | 单击行 | 详情面板展开该记录 |
| 上下移动选择 | `↑` / `↓` | 选中行变化并把目标滚进窗口 |
| 标记 / 备注 | 详情里 `★ 标记` 或备注框（回车保存） | 列表行出现 ★；备注随会话恢复保留 |
| 复制类操作 | 行右键 或 详情按钮 | 剪贴板 + 状态栏提示 |
| 行右键菜单 | 右键任意行 | `复制 URL` / `复制 cURL` / `复制 Python` / `复制 Node fetch` / `重放` / `导出此条` / `另存响应体` |
| 跳回最新 | 点「↓ N 条新记录」 | 列表滚到底并清零未读 |
| 清空列表 | 第 1 行 `清空` | 内存记录清空（会话文件不受影响） |

**虚拟滚动**：列表只渲染可见窗口的行（DOM 恒定约 30 余行），条数再多也不影响滚动；**导出、复制、统计、详情始终按内存里的全部记录算**，与窗口显示多少行无关。

### 4.3 详情面板的每个分区

| 分区 | 内容 |
|---|---|
| 概要 | URL、方法、状态、类型、MIME、远端 IP、协议、耗时、大小、时间 |
| 发起者 | CDP `initiator`：类型 + 来源 URL + **JS 调用栈（最多 12 帧，`函数 @ 文件:行:列`）**；点「复制发起者」拿到纯文本 |
| 耗时分解 | DNS / 连接 / TLS / 发送 / 等待（TTFB）/ 下载 六段（毫秒）；`下载` = 总耗时 − 首字节，含排队与主进程开销 |
| 失败 | 失败原因与 `blockedReason`（被拦截 / 被取消 / DNS 失败等） |
| 重定向链 | 每一跳的 `状态 原始 URL → Location` |
| 请求头（原始，含 Cookie） | 原始头优先、去重后逐行显示 |
| 请求体 | POST/PUT 等请求体原文 |
| 响应头（原始，含 Set-Cookie） | 同上 |
| 响应体 | 文本直接显示，二进制只报大小；超 200KB 默认截断，可「查看全文」；JSON 可「美化 JSON / 还原原文」；可「另存为文件」 |

### 4.4 WebSocket 视图

- 面板 `WebSocket` 标签页查看收发帧（方向、opcode、内容、时间）。
- `暂停`：暂停后新帧不再进列表（数据仍在主进程）；`帧内容过滤`：按子串过滤；`清空显示`只清界面。
- 帧上限 2000 条，超出丢弃最早的。

### 4.5 瀑布视图

按时间轴画条、按状态着色、跟随筛选；点击条回到列表并展开该条详情。用于快速判断「谁先谁后 / 谁慢」。

### 4.6 统计概览（工具栏 `统计概览`）

按域名 / 类型 / 状态的条数与体积汇总，外加「最慢」「最大」各 top10，用来快速定位大文件与慢接口。

### 4.7 抓包快照对比（工具栏 `快照`）

1. 点 `快照` → 弹窗里点 `保存当前`：把当前标签的记录存成快照（`METHOD url` + 状态 + 耗时 + 大小，只留内存）。
2. 改动页面（登录、翻页、改参数）后再点 `保存当前`。
3. 点 `与上一个对比`：三张表列出**新增 / 消失 / 变化**（耗时差 >20% 才算变化）。
   注：最多保留最近 2 个快照，重启即清空。

## 5. 拦截与伪装

全部在第 2 行工具栏，除特别注明外**立即生效**：

| 控件 | 选项 / 写法 | 说明 |
|---|---|---|
| 拦截模式 | `不拦截` / `屏蔽图片·媒体·字体` / `关键字屏蔽` | 被拦的请求根本不会到达服务器；刷新后体现 |
| 关键字 | 逗号分隔 | 命中的 URL 直接取消 |
| 仅记 XHR/Fetch | 勾选 | 列表只收接口请求，页面资源不记录 |
| 限速 | `不限速` / `3G` / `慢速` | CDP 模拟网络条件，立即生效，用于测页面的弱网行为 |
| UA | 预设或「自定义」（选中后出现输入框） | 刷新后生效；可点「应用到所有标签」 |
| 请求头 | `k=v;k=v`（分号或换行分隔，如 `Referer=https://x; X-Token=abc`） | 注入到每个请求；格式错会提示 |
| 代理 | `http://host:port` / `socks5://host:port`（也支持 `;` 分隔的多段规则） | 写 `direct://` 强制直连；清空恢复直连 |
| 测代理 | 按钮 | 用当前代理真发一次请求，显示解析到的代理与真实状态/耗时 |
| 落盘 | 见 [第 10.5 节](#105-规则落盘边抓边写) | 边抓边把命中的响应体写进目录 |
| Mock | 见 [第 6 节](#6-mock-改写本地应答) | 命中规则的请求本地应答 |
| 间隔 | 0–10000ms | 请求最小间隔（礼貌抓取），被拦截的请求不消耗间隔 |
| 应用所有标签 | 按钮 | 把当前 UA / 请求头 / 限速刷到所有已打开标签 |

**证书与认证**（在「设置」弹窗里开关，见第 15 节）：

- 忽略证书错误：内网自签名站点勾选后再访问。
- Basic 认证用户名 / 密码：填了就用它自动应答，不弹系统框；不填则取消请求并在状态栏提示。

## 6. Mock 改写（本地应答）

**用途**：页面依赖的接口挂了 / 在改版 / 要造异常分支时，不改代码、不用后端，让页面拿到你指定的响应。

### 6.1 打开与配置

1. 第 2 行工具栏点 `Mock` → 打开「Mock 改写」弹窗。
2. 顶部 `开启` 勾上（关闭状态下规则不生效）。
3. 每条规则一行：

| 列 | 写法 | 说明 |
|---|---|---|
| 启用 | 勾选 | 临时停用某条规则 |
| URL 正则 | 如 `^http://127\.0\.0\.1:8080/api/user` | **按顺序匹配，第一条命中生效**；空正则不匹配 |
| 状态 | 如 `201` | 100–599 |
| 响应头 | 每行 `名称: 值` | `Content-Length` 会被忽略（由浏览器按 body 长度生成） |
| 响应体 | 文本（JSON 直接写一行） | 逐字返回；二进制请用「设为 mock」自动带 base64 标记 |
| 命中 | 只读 | 该规则被命中次数 |
| 删除 | 按钮 | 删掉该行，点「保存」后生效 |

4. `新增规则` 追加空行，`保存` 写入设置并立即对新请求生效（最多 30 条规则）。

### 6.2 从抓包一键生成规则（推荐）

1. 先在列表里选中那条真实请求（详情打开）。
2. 点详情顶部 `设为 mock`：工具会用它生成一条规则——`urlRe` = `^origin+pathname`（查询串任意都命中）、状态码取记录状态、响应头与响应体取记录内容。
3. 想改响应体就再点 `Mock` 打开弹窗编辑（保留 `bodyBase64` 标记的二进制记录会以 base64 文本显示）。

### 6.3 行为与注意

- 命中即本地应答；**未命中的请求一律原样放行**（不干扰正常抓包）。
- 规则、开关、命中数都随设置持久化；改规则或切换开关会**重置命中计数**。
- Mock 开启期间工具会临时：**关闭标签的 HTTP 缓存**（否则命中缓存的请求不经拦截层）、**摘掉资源拦截/限速用的 webRequest 拦截器**（实测二者同层共存时浏览器会丢掉本地应答的状态码与响应头）。关闭 Mock 后自动恢复，这几项功能即刻回到生效状态。
- 抓包列表照常记录 mock 命中的请求（状态码/响应体就是你给的那份），方便对照。

## 7. 页面数据与会话数据

第 1 行 `会话数据` 打开一个弹窗，四块内容：

### 7.1 Cookie

- 逐条编辑：列表显示 domain / path / 名称 / 值 / 属性，改值即写回（失败会回滚并提示）。
- `新增 Cookie`：填名称与值，挂到当前页 origin。
- `导入 Cookie`：粘贴 `a=1; b=2` 或 JSON 数组。
- `删除`：单条删除。
- 导出：`导出 Cookie JSON`（`<主机>-cookies-<时间>.json`）/ `导出 Cookie Netscape`（`<主机>-cookies-<时间>.txt`，Netscape 格式，可直接给 `curl -c/-b`、wget 用）。

### 7.2 Storage（localStorage / sessionStorage）

- 两个分区各自列表：改值即写回页面、`删除` 单条、`新增` 一条。
- `导入 Storage` 批量写 localStorage：支持 `{"k":"v"}` 或每行 `k=v`，写入后自动刷新页面。

### 7.3 页面数据快照

- 页面 HTML、`document.cookie`、localStorage、sessionStorage 的当前值都能在这里查看（也可用 `导出全部` 一次性落盘）。

### 7.4 清理数据（工具栏 `清理数据`）

勾选要清的项（Cookie / Storage / 缓存 / 日志 / 会话文件 / 录制记录）→ `确认清理`：逐项执行并逐项报结果。**不可撤销**，清 Cookie/Storage 会让相关站点退出登录。

## 8. 提取与自动化

### 8.1 CSS / XPath 提取（工具栏 `CSS 提取`）

1. `CSS 提取` 打开弹窗：`行选择器`（如 `.item`；XPath 加 `xpath:` 前缀）+ 每行一个字段 `名称=选择器[@属性]`（如 `标题=.t`、`链接=a@href`、`正文=@html`）。
2. 点 `提取`：预览前 20 行，可 `导出 CSV` / `导出 JSON`。
3. 选择器旁有 `拾取` 按钮：在页面上悬停高亮、点选即得 CSS 选择器（Esc 取消），自动回填；「拾取到字段」把选择器追加到字段行末尾。
4. 弹窗里还能存 / 取 **任务预设**（页数、间隔、起始终点 URL、行列选择器，最多 20 条）。

### 8.2 翻页 + 提取（弹窗内 `翻页+提取`）

填页数与间隔（可另填起始 URL）→ 每页跑一遍当前选择器、自动识别「下一页」翻页，跑完把各页行合并为一张表：`_page` 列标明来源页；重复行只统计条数不删除；过程中可点工具栏 `停止`。

### 8.3 自动滚动 / 自动翻页（第 3 行）

- `自动滚动`：填轮数（1–50）→ 滚到底触发无限加载，直到页高不再增长或轮数用尽。
- `自动翻页`：填总页数（1–100）与每页间隔（200–60000ms）→ 自动找「下一页」翻到底；`停止` 可随时中断。
- 结束后状态栏显示结果与原因（完成 / 未找到下一页 / 已停止 / 超时）。

### 8.4 页面清单（工具栏 `页面清单`）

一次性取出页面上的**链接 / 图片 / 表单 / 表格**：可 `导出清单 JSON`，表格可 `表格 → CSV`。

## 10. 导出与交付

### 10.1 全量与筛选导出

| 按钮 | 产物 | 内容 |
|---|---|---|
| `导出全部` | `<主机>-capture-<时间>.json` | 页面数据 + Cookie + **全部请求记录（含响应体）** + WebSocket 帧 |
| `导出筛选结果` | 同上（只含当前筛选出来的记录） | 与列表显示一致，快捷键 `Ctrl+S` |
| 详情 `导出此条` / 行右键 `导出此条` | 同上（单条） | 适合当问题单附件 |
| `导出 HTML` | `<主机>-page-<时间>.html` | 当前页 HTML |
| `导出 Cookie` | `<主机>-cookies-<时间>.json` / `<主机>-cookies-<时间>.txt`（Netscape） | Cookie 存储 |
| `导出 HAR` | `<主机>-capture-<时间>.har` | HAR 1.2，可直接拖进 Chrome DevTools 的 Network 面板 |
| `导出 Postman` | `<主机>-postman-<时间>.json` | Collection v2.1，可导入 Postman / Insomnia |
| `导出 OpenAPI` | `<主机>-openapi-<时间>.json` | OpenAPI 3.0.3：路径模板（数字段归一为 `{id}`）、查询参数、请求体与响应示例（见 10.4） |
| `复制表格` | 剪贴板 Markdown | 当前筛选结果转 Markdown 表格 |
| 详情 `复制代码…` / 行右键 | 剪贴板 | cURL / Python requests / Node fetch / Node axios |
| 详情 `另存为文件` / `请求体另存` | 单文件 | 响应体 / 请求体单独落盘 |

### 10.2 响应体批量存盘（工具栏 `响应体存盘`）

选目录 → 把**本次抓到的全部响应体**按 `序号_方法_主机路径.扩展名` 平铺写入（重名加 `-1`、`-2`），二进制按原始字节写。适合「先把素材全部抓下来」再慢条斯理分析。

### 10.3 单条另存

详情里：`另存为文件`（响应体）、`请求体另存`（请求体）；行右键菜单同样有「另存响应体」。

### 10.4 OpenAPI 3 导出说明

- 只导出**当前页同源的 2xx 记录**；其他域名 / 非 2xx 会统计在 `info.description` 的「跳过 N 条」里。
- 路径模板：`/api/item/123` 与 `/api/item/456` 会归并成一个 `/api/item/{id}`（路径参数名固定 `id`，示例取首次出现的值）。
- 请求体按内容判定：可 `JSON.parse` → `application/json`；`k=v&k=v` → `application/x-www-form-urlencoded`；其他 → `text/plain`。
- 响应示例取该 `METHOD + 路径模板` 首次命中记录的状态码、MIME 与响应体（能 `JSON.parse` 就用解析值，否则截断 64KB）。
- 最多 500 个操作，超出丢弃并写进 description。
- 用法：喂给 mock 服务（配合第 6 节）、生成文档站、给前端当契约。

### 10.5 规则落盘（边抓边写）

1. 第 2 行 `落盘` 打开「响应体落盘规则」：`开启` + `URL 正则`（留空 = 全部）+ `类型`（全部 / 仅 XHR·Fetch / 仅 Document）+ `MIME 关键字`（如 `json,csv`）+ `目录`（`选择…` 挑目录）。
2. 保存后**命中的响应体边抓边写**到目录，按**站点目录树镜像**：`site/<主机>/<路径>`，查询串在扩展名前插 `_q_<sha1 前 8 位>`，重名在扩展名前加 `-1`、`-2`。
3. 列表里该行标记 `已落盘：<站点相对路径>`；状态栏胶囊显示累计个数与体积。
4. 单次运行上限 2000 个文件 / 512MB，到顶只提示一次；改规则或重启重置计数。

### 10.6 文件名规则

- 导出类文件名统一 `<主机名>-<kind>-<ISO 时间戳>.ext`，时间戳里的 `:` 与 `.` 换成 `-`（例：`example.com-capture-2026-10-14T03-00-00-000Z.json`）。
- 时间戳、主机名对不上时说明是「另存为」自定义名。

## 11. 离线包：离线复现一个页面

**用途**：抓完一个页面后，把「页面 HTML + 它的静态资源」按原始路径镜像成一个目录，双击入口 HTML 就能离线打开；同时导出 JS 清单、抓包记录与加密线索，供后续搭测试环境或分析请求加密。

### 11.1 操作

1. 打开目标页面（等它加载完、需要登录就先登录）。
2. 第 3 行 `离线包` → 弹窗里选导出目录（`选择…`，留空会弹系统目录框）。
3. 按需勾选 `附 network.json`（抓包请求头/请求体/响应头）与 `附 hints.json`（加密线索定位）。
4. 点 `导出离线包`：完成后显示文件数、字节数、缺失项数量、耗时与入口路径；`打开目录` 直接跳过去。
5. 双击「入口 HTML」即可离线打开（样式 / 图片 / 内联脚本都生效）。

### 11.2 产物结构

```
<导出目录>/
├─ manifest.json     文件清单 / 缺失清单 / 计数 / 选项（version 1）
├─ network.json      本次抓包记录：方法/URL/状态/耗时/大小/发起者/耗时分解/请求头/请求体/响应头（不含响应体）
├─ js/
│  ├─ index.json     脚本清单：url / local / bytes / kind(external|dynamic|inline)
│  └─ _inline/001.js 页面内联脚本副本（文件头注明来源页面）
├─ hints.json        关键词 → 命中（文件:行 + 该行截断文本）
└─ site/<主机>/...   镜像站：入口 HTML（引用已改写为相对路径）与全部静态资源
```

### 11.3 规则与边界

- **只使用已抓到的字节，绝不补发请求**：没抓到的资源写进 `manifest.missing`（原因：未抓到响应体 / 写入失败 / 路径冲突），不影响其它文件落盘。
- 只做当前页 + 它的静态资源（不递归子页面）；JS 收全部 `<script>`（外链 + 运行时动态加载到的）+ 内联脚本副本。
- HTML / CSS 里的引用会重写成相对路径（绝对 URL、`//host/path`、`/path`、相对引用四种形态）。未命中映射的引用原样保留。
- `network.json` 里带不上响应体（避免几十 MB），响应体请用「响应体存盘」或规则落盘单独取。

## 12. 请求复现与加密分析

### 12.1 重放请求（详情 `重放请求` / 行右键 `重放`）

弹窗里可改写：方法、URL、请求头（每行 `名称: 值`，大小写不敏感覆盖）、请求体；默认预填抓到的原始内容。点 `发送`：
- 结果就地展示（响应体截断 1MB）并追加到详情面板；**不会混入抓包列表**。
- 用它可以验证「改一个参数是否通过」「同一请求是否可重放」——签名类接口若报错，多半是时间戳/随机数，回头用 12.2 定位算法。

### 12.2 请求发起者（谁发的这个请求）

详情 `发起者` 段给出 CDP 的 initiator：

```
script · http://site/js/app.min.js:1
fetch @ http://site/js/app.min.js:1024:87
...（最多 12 帧）
```

`函数 @ 文件:行:列` 直接指向发起调用的代码位置；点 `复制发起者` 拿到纯文本，配合「执行 JS」在页面里下断点或打印该行上下文。

### 12.3 耗时分解（慢在哪一段）

详情 `耗时分解` 六段：`DNS / 连接 / TLS / 发送 / 等待 / 下载`。

- 全是 0：连接复用（keep-alive）或页面缓存，属正常。
- `等待` 大：服务端处理慢（TTFB）。
- `下载` 大：响应体大 / 带宽不足（注意它含排队与主进程开销，不是纯传输时间）。
- HAR 导出的 `timings` 同步填实，可在 DevTools 里看同一份数据。

### 12.4 用 hints.json 定位加密代码

`hints.json` 把**请求参数名/值**在已保存的 JS 文本里逐行检索，输出 `{ keyword, kind: param|value, hits: [{ file, line, text }] }`：

1. 关键词来源：URL 查询键 ∪ POST/PUT 的键（JSON 顶层键或 `k=v` 拆键）∪ 这些键用过的值（去重、长度 3–64、跳过纯数字；每个键最多 3 个值）。
2. 检索范围：离线包里已保存的 JS（外链 + 内联），单文件 ≤ 8MB、总量 ≤ 64MB；每个关键词最多 3 条命中，命中行截断 200 字符。
3. 用法：搜 `sign` / `timestamp` / `nonce` 这类关键词的 `hits[0].file:line`，直接打开对应 JS 文件那一行；没有已保存的 JS 时 `keywords` 为空数组。

### 12.5 组合拳（推荐流程）

1. 抓包 → 列表里找到目标接口 → 看 `发起者` 拿到调用点（12.2）。
2. `导出离线包` 连续导出（勾上 network.json + hints.json）。
3. 打开 `hints.json` 找关键词所在行 → 打开 `site/.../xxx.js` 那一行。
4. 用「执行 JS」在页面里复现加密：调该函数、打印中间值（CDP 执行不受 CSP 限制）。
5. 用「重放请求」验证你构造的签名是否被接受（12.1）。

## 13. 录制与回放

### 13.1 录制

1. 第 3 行 `● 开始录制`（可先勾 `点击截图`：每次点击额外存一张视口截图，单次最多 300 张）。
2. 期间面板顶部浮层显示「录制中 · 最近 20 条」实时视图。
3. 再点一次停止（或直接关窗，也会生成摘要）。
4. 产物落到「录制目录」：`rec-<时间戳>.jsonl`（每行一个事件）+ 同名 `.md` 时间线摘要 + `rec-...-click-NNN.png` 截图；工具栏 `打开摘要` 直接打开最近一次录制的 `.md`，`录制目录` 在文件管理器里定位录制品。

记录内容：点击 / 输入 / 变更 / 提交 / 按键 / 滚动（含元素标签链与 CSS、XPath 选择器）+ 请求与响应（含头与响应体）+ 导航 + WebSocket 帧；密码输入自动掩码。

### 13.2 录制历史（`录制历史`）

- 列表按时间倒序，显示条数、动作数、`.md` 摘要、截图张数、占用（目录超 1GB 会提醒）。
- 点条目可看 `.md` 时间线；`过滤` 框按关键字筛条目。
- 操作：`重放`（倍速 1×/2×/4×/不等间隔，失败即停可关，可选「重放导航」）、`导出回放脚本`（独立 Playwright 脚本 `replay-<录制名>.js`，密码行为空并注明手填）、`删除此条`（弹出「删除录制」确认框，点 `确认删除` 后连同 `.md` 与截图一起删）、`打开日志所在文件夹`。

### 13.3 重放录制

在「录制历史」里点 `重放` → 弹窗选倍速与选项 → `开始`（过程中可 `停止重放`）。重放会真实驱动页面，因此目标站点最好处于可重放状态（登录态、后端可用）。

## 14. 多标签与会话持久化

### 14.1 标签

| 操作 | 入口 | 说明 |
|---|---|---|
| 新建 | 标签栏 `＋` | 新标签默认打开当前站点 |
| 切换 | 点标签片 | 每个标签**独立抓包**，列表/详情/瀑布跟着切 |
| 关闭 | 标签片上的 `✕` / 右键 `关闭` | 关闭后 10 秒内可「撤销」（恢复新视图 + 原抓包记录 + 原 URL） |
| 关闭其他 | 标签右键 | 只留当前标签 |
| 复制 URL / 重新加载 | 标签右键 | — |

后台标签**继续抓包与跑自动化**（不节流），代价是标签越多 CPU 占用越高；UA / 请求头 / 限速只对「当前活动标签」立即生效，可用 `应用到所有标签` 一键同步。

### 14.2 会话持久化

- 运行中每 30 秒（有变化时）写一次 `sessions/last.json`；退出时同步写一次。
- 下次启动若发现未过期（7 天内）的会话，面板顶部出现横幅：`恢复` / `忽略`。
- `恢复`：把记录灌回当前标签（标记 ⟲ 表示来自上次会话），并把保存时的标签布局在后台重新打开（最多 5 个标签，只重开 URL，不抢当前标签，页面内容不还原）。
- `忽略`：删除会话文件。

## 15. 设置、备份与诊断

### 15.1 设置（工具栏 `设置`）

### 15.3 诊断日志

## 18. 常见任务配方

### 18.1 抓一个登录后的接口列表

1. 地址栏打开站点 → 在页面区域完成登录（Cookie / localStorage 保存在持久分区，重启仍在登录态）。
2. 面板过滤框输入 `method:post` 或接口关键字，勾 `仅记 XHR/Fetch` 减少噪声。
3. 详情里核对 `响应头（原始，含 Set-Cookie）`；需要认证参数就 `复制 cURL` 到终端复跑。
4. `导出筛选结果` 留档。

### 18.2 批量把接口响应体落到硬盘（供离线分析）

1. 第 2 行 `落盘` → 开启，URL 正则填接口前缀（如 `/api/`），MIME 填 `json`，选目标目录。
2. 正常操作页面（翻页、点按钮）→ 每命中一条就落盘一个文件，路径是 `site/<主机>/<接口路径>.json`。
3. 状态栏胶囊核对个数与体积；到 2000 个 / 512MB 会提示一次。

### 18.3 离线复现一个页面（给测试环境当基线）

见 [第 11 节](#11-离线包离线复现一个页面)：`离线包` → 勾 network.json + hints.json → 导出 → 双击入口 HTML 验证。

### 18.4 后端没搭好，先让页面跑起来

1. 打开页面（接口报错无所谓）。
2. 逐条选中需要的接口 → 详情 `设为 mock`（自动带去真实响应）。
3. 打开 `Mock` 弹窗核对状态码/响应头/响应体；`保存` 后刷新页面 → 页面用 mock 数据跑通。
4. 需要造异常分支就复制一条规则、改状态码（如 `500`）与响应体。

### 18.5 从抓包生成接口文档

1. 把要覆盖的接口都点一遍（列表里状态 2xx 的记录会被纳入）。
2. 点 `导出 OpenAPI` → 得到 `*.json`；把它导入文档站 / mock 服务 / Swagger UI。

### 18.6 翻页抓列表 + 导出

1. `CSS 提取` 里填好行选择器与字段（可用 `拾取`）。
2. 弹窗里点 `翻页+提取`：填页数、间隔、起始 URL。
3. 跑完预览合并结果（`_page` 列标明来源页）→ `导出 CSV` / `导出 JSON`。
4. 常用组合可先存成**任务预设**，下次一键调用。

### 18.7 定位一个加密接口的签名算法

见 [12.5 组合拳](#125-组合拳推荐流程)。

### 18.8 把一次操作录下来交给别人复现

1. 勾 `点击截图` → `● 开始录制` → 完整走一遍操作 → 停止。
2. `录制历史` → `导出回放脚本`（`replay-*.js`，Playwright）或直接 `重放` 自查。
3. 把 `rec-*.jsonl` + `.md` + 截图 + 脚本一起打包交付（截图能解释每一步点在哪）。

## 19. 故障排查

| 症状 | 原因 / 处理 |
|---|---|
| 状态栏一直不是「抓取中」 | CDP 未挂上：页面 DevTools 已打开会冲突，先关掉它；或重启工具 |
| 列表不出记录 | 看第 2 行是否处于「拦截模式」且勾了「仅记 XHR/Fetch」；过滤框是否残留条件；该标签是否被暂停（`Ctrl+P`） |
| 页面样式错乱 / 图片不显示 | 「拦截模式 = assets」会屏蔽图片·媒体·字体，切回 `none` 并刷新 |
| 站点打不开 / 证书报错 | 内网自签名站点：设置里勾「忽略证书错误」；需要 Basic 认证：填用户名/密码 |
| 代理不生效 | 写全 `scheme://host:port`；点 `测代理` 看解析结果与真实请求状态；多段规则用 `;` 分隔，强制直连写 `direct://` |
| Mock 生效但状态码/响应头不对 | 检查是否同时开着别的拦截层；工具在 Mock 期间会临时摘掉 webRequest 拦截器（见 6.3），若你改过代码请保持这一行为 |
| Mock 不生效 | 规则 `启用` 未勾 / `开启` 未勾 / URL 正则与真实 URL 不匹配（用「设为 mock」生成最稳）；跨域或命中缓存的请求请刷新后再看 |
| 面板一片空白（列表没行也没报错） | 渲染进程可能崩过一次：看 `logs/app.log` 里的 `render-gone` 行；重启工具，必要时把复现步骤与日志一起反馈 |
| 截图是空白 | 窗口被其它窗口遮挡时 Chromium 推迟合成：把工具窗口置顶/聚焦后再截 |
| 老机器卡顿 | 设置里确认是否已自动降级软件渲染；减少同时打开的标签；用「仅记 XHR/Fetch」减少记录量；列表已按窗口渲染，条数不再影响滚动 |
| 关掉的标签找不回来 | 撤销只有 10 秒且只保留最近一次关闭 |
| 重启后标签没了 | 会话恢复只恢复记录与标签布局（在后台重开），不还原页面内容与表单状态 |
| 下载文件找不到 | 工具不接管保存路径，文件按 Chromium 默认落到系统下载目录；状态栏与提示里有开始/完成提示 |
| 导出的离线包打不开样式/图片 | 打开 `manifest.json` 看 `missing`：未抓到的资源不会被补发（这是有意设计），重新抓一次该页面再导出 |

## 20. 已知限制

以下限制与设计取舍摘自 README 的「已知限制」小节（保持同步）：

- 抓取记录上限 5000 条/标签、单条响应体 32MB、响应体总量 256MB、WebSocket 帧 2000 条，超出按策略截断或丢弃并提示。
- 会话恢复只覆盖最近 5 个标签的 URL（在后台重新打开）、记录、标记与备注，不还原页面内容与表单状态。
- UA / 请求头 / 限速只对当前活动标签立即生效；后台已存在的标签不会跟着改（用 `应用到所有标签` 手动同步）。
- 列表按窗口渲染（虚拟滚动）：DOM 只保留可见窗口的行，滚动时行节点会复用重建；导出、复制、统计、详情始终按内存里的全部记录算。
- 列表排序 / 域名分组重建渲染顺序表；内存里（导出、编号、会话恢复）始终按时间顺序；流式追加 / 更新按 100ms 合并重建一次。
- 抓包事件按 100ms 合并推送到面板：列表行最多晚 100ms 出现（切标签与「清空」会立即冲刷）。
- 响应体全文搜索只覆盖已保存的**文本**响应体；改过滤条件后约 300ms 重算。
- 规则落盘按站点目录树镜像（`site/<host>/<路径>`），单次运行上限 2000 个文件 / 512MB，改规则或重启重置计数。
- Mock 开启期间关闭标签 HTTP 缓存并临时摘掉 `webRequest` 拦截器（因此资源阻断与请求最小间隔在 Mock 期间暂停生效），关闭后恢复；规则最多 30 条、按顺序匹配、改规则即重置命中计数。
- 耗时分解里的「下载」= 总耗时 − 首字节，包含排队与主进程/渲染开销；连接复用时 DNS / 连接 / TLS 为 0。
- 离线包只镜像当前页与其静态资源（不递归），且**只使用已抓到的字节**；缺失项记进 `manifest.json`。
- 「清理数据」立即生效且不可撤销；清 Cookie / Storage 会让相关站点退出登录。
- 窗口不带系统菜单栏，因此没有页面缩放快捷键；输入框内的编辑快捷键不受影响。
- 录制写盘走异步队列：极端崩溃（断电/杀进程）最多丢最后 250ms 的事件；正常停止与退出会同步补写。
- 会话写盘每 30 秒一次（有变化时）且分片序列化；退出路径仍是同步写，超大会话退出时略慢，换来「随时关窗也不丢」。
- 系统保存 / 目录对话框需要人工点选，无法纳入自动化测试（自检通过传入路径参数绕过）。

## 21. 文件、目录与命名规则

### 21.1 配置与数据目录（`%APPDATA%\web-capture-tool`）

```
settings.json            设置（含拦截、UA、代理、落盘规则、Mock 规则、任务预设等）
sessions/last.json       会话快照（7 天内有效，重启后横幅可恢复）
recordings/              录制品：rec-*.jsonl / rec-*.md / rec-*-click-*.png / replay-*.js
logs/app.log             诊断日志（滚动保留一代 app.log.1）
Partitions/capture/      Chromium 持久分区（Cookie / localStorage / 缓存，登录态就在这）
```

### 21.2 产物命名速查

| 产物 | 命名 / 结构 |
|---|---|
| 导出全部 / 筛选 / 单条 | `<主机>-capture-<ISO 时间>.json` |
| 当前页 HTML | `<主机>-page-<ISO 时间>.html` |
| HAR | `<主机>-capture-<ISO 时间>.har` |
| Postman | `<主机>-postman-<ISO 时间>.json` |
| OpenAPI | `<主机>-openapi-<ISO 时间>.json` |
| Cookie | `<主机>-cookies-<ISO 时间>.json`（JSON）/ `<主机>-cookies-<ISO 时间>.txt`（Netscape） |
| 截图 | `<主机>-shot-<ISO 时间>.png` |
| 响应体批量存盘 | `序号_方法_主机路径.扩展名`（平铺，重名加 `-1`、`-2`） |
| 规则落盘 | `site/<主机>/<路径>[.ext]`，查询串插 `_q_<hash>`，重名在扩展名前加 `-1`、`-2` |
| 离线包 | `manifest.json` / `network.json` / `js/index.json` / `js/_inline/NNN.js` / `hints.json` / `site/**` |
| 录制 | `rec-<时间戳>.jsonl`、`rec-<时间戳>.md`、`rec-<时间戳>-click-NNN.png`、`replay-<录制名>.js` |

### 21.3 扩展名映射

工具按 MIME 推断扩展名：`json` / `html` / `css` / `js`（javascript、ecmascript）/ `svg` / `png` / `jpg` / `gif` / `webp` / `woff2`（font、woff）/ `xml` / `txt`（其他 `text/*`）/ `bin`（其余）。
